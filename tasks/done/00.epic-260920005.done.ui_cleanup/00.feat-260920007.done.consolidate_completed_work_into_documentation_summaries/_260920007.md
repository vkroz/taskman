Consolidate selected completed work into a concise summary stored in project documentation, removing the individual items from the ordinary task list. The user wants lasting reduction of historical clutter, beyond filtering completed tasks out of view.

## Required outcomes

- Users can select a set of completed work items for consolidation.
- Produce a concise documentation summary of the delivered outcomes, significant decisions and reasons, and verification evidence.
- Consolidated items no longer appear individually in the ordinary task list.
- Provide the operation through the CLI and make it discoverable in the UI.
- Preserve the rule that completed requirements and evidence cannot be edited in place.

## Decisions still open

Determine whether original records remain in an archive or are removed after summarization. Define treatment of parent-child relationships and references from other work, summary destination and review, and how consolidated history can be retrieved. These decisions must be resolved before implementing consolidation.

## Local acceptance

On representative completed work, demonstrate summary creation in documentation and removal of individual items from the ordinary task list. Verify retained outcomes, rationale and evidence, handling of references, and retrieval according to the agreed retention design. Open work remains unaffected.

Draft requirements only; no existing tasks are to be consolidated or removed during this capture.
