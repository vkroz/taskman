Add drag-and-drop reordering to the displayed task list using the shared persisted ordering operation.

## Acceptance criteria

- A user can drag a task row to another valid position in the displayed task list.
- The interface makes the prospective drop position understandable and, after drop, renders the task at that position.
- Upward and downward moves reflect higher and lower priority respectively.
- Refreshing or reopening the UI restores the accepted order from storage.
- The interaction does not change the task's parent or lifecycle status and does not transfer work between lists or collections.
- A rejected reorder leaves the prior order visible or restores it and presents an actionable error.

## Local verification

- Add UI or HTTP integration coverage for successful reorder, rejected reorder and restored persisted order.
- In a browser, drag representative tasks upward and downward, verify their positions immediately and after refresh or reopen, and inspect that parent and status are unchanged.
