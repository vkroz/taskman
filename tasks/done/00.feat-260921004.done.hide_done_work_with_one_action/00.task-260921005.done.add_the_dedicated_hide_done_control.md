Add the dedicated one-action control for excluding `done` tasks and integrate it with the existing filter state.

## Acceptance criteria

- The task-list interface replaces the unnecessary ascending/descending sort-direction controls with a dedicated hide-done control that does not require the general filter form to open.
- Activating it excludes `done` tasks and shows an active state that is accessible without relying only on color.
- Deactivating it restores done tasks subject to the selected view, search, epic scope and other active filters.
- The exclusion combines with general filter criteria using the behavior defined by the parent feature, without removing or resetting those criteria.
- The general-purpose field filter remains available and no ascending/descending sorting or sort-direction control is added.
