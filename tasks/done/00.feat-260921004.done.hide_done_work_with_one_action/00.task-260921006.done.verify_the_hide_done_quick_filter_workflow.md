Establish automated and browser evidence that the hide-done control works as one action, communicates its state and composes with existing task-list constraints after replacing the unnecessary sort-direction controls.

## Acceptance criteria

- Focused tests demonstrate that activation excludes `done` rows and deactivation restores eligible `done` rows.
- Focused tests demonstrate composition with the selected view, keyword search, epic scope and at least one general-purpose field filter while preserving access to that filter.
- Browser verification confirms the control requires no general-filter setup and visibly communicates active state without relying only on color.
- Browser verification confirms other active constraints govern which rows return when the control is deactivated.
- Inspection confirms the unnecessary ascending/descending controls were replaced and no sort-direction control was added.
- The full test suite passes.
