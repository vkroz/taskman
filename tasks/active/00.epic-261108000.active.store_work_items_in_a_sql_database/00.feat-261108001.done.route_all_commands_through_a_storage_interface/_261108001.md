## Outcome

All CLI commands and the workspace UI reach work items through one storage interface. The current file layout is the first implementation. Nothing visible to the user changes.

## Requirements

- No command module or UI module reads or writes task files directly, or imports file-layout, name-grammar or YAML helpers.
- The interface covers every operation the CLI and UI use, including lifecycle rule checks. Rule checks run the same way for every backend; only persistence differs.
- A backend is selected through configuration, with `file` as the only option for now.
- A contract test suite exercises the interface and runs against the file backend.

## Acceptance criteria

- Existing tests on `main` pass without changes to their assertions.
- A search of `commands/` finds no import of `model.layout`, `model.names` or `model.yaml_io`.
- The contract suite covers create, nest, depend, ready, record, close gates, immutability, reorder, discard, consolidate and history.
