File-format tools belong to the file backend. Their commands only delegate.

- `validate`: name/frontmatter drift and grammar checks move into the file backend. Backend-neutral checks (parent references, cycles, task-is-leaf) run through the interface for any backend.
- `migrate` (legacy file format conversion) moves into the file backend. On another backend it would fail with a clear message; only `file` exists now.
