## Outcome

`taskman` can run as an HTTP server over a SQL backend. The CLI and the workspace UI use it through a `remote` backend.

## Requirements

Covers epic R8.

- The API covers every storage-interface operation. Lifecycle rules run on the server.
- Every API call needs a token, except liveness and readiness checks.
- The CLI reads the token from user configuration or the environment, bound to the server URL. A repository file cannot send the token to another host.
- The workspace UI served by the server offers the same operations as the local UI.

## Acceptance criteria

- The contract suite passes against the remote backend.
- Two CLI processes with different working directories share one project through a local server.
- Calls without a valid token get 401 and change nothing.
