## Outcome

The Taskman server runs on Cloud Run against an existing Cloud SQL for PostgreSQL instance.

## Requirements

Covers epic R9.

- One container image. All settings come from environment variables and mounted secrets: port, Cloud SQL socket or connection, database, user, password, access token.
- The schema upgrade runs as a separate step before a new revision serves traffic.
- Documentation lists the prerequisites (instance, database, user, secrets, service account roles) and the deploy steps with placeholders. The repository holds no organization-specific identifiers.
- Cloud SQL provisioning and IAM changes are out of scope.

## Acceptance criteria

- The image runs locally against Postgres through a unix socket with Cloud Run style environment variables, and readiness reports the database state.
- The deploy document's steps run against a placeholder-substituted project without editing repository files.
