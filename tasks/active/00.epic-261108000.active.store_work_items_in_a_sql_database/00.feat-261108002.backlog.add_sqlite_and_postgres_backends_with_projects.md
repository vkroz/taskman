## Outcome

Work items persist in SQLite or Postgres, selected per repository, with projects and schema versions.

## Requirements

Covers epic R2–R7 for the `sqlite` and `postgres` backends.

- Repository configuration selects backend, connection and project. A Postgres password can come from an environment variable or a mounted secret file.
- Postgres connects by connection string or by Cloud SQL unix socket path.
- A schema upgrade command records and applies versions in order.

## Acceptance criteria

- The contract suite passes against SQLite and against Postgres 16.
- Two projects in one database do not see each other's items.
- Concurrent writers from two processes produce no lost updates and no duplicate IDs.
- The upgrade command on a current database exits 0 and changes nothing.
- The suite runs without Docker when only SQLite tests are selected.

## Verify

`cd taskman && uv run pytest` with and without a Postgres test database URL.
