## Outcome

Taskman reads its storage settings from environment variables and a `.env` file (decisions D6, D7).

## Scope

- Settings: backend, database URL, Cloud SQL socket, database name, user, password, password file. No setting selects a project (decision M5).
- `.env` is read from the working directory's repository root. Variables already set in the environment win.
- SQLite without a path uses `~/.local/share/taskman/taskman.db`.
- Passwords and tokens come only from the environment or a secret file; they never appear in output or errors.
- `taskman help` and the README list every setting with one worked example each for SQLite, local Postgres and Cloud SQL socket.

## Acceptance criteria

- Tests cover: `.env` loading, environment precedence, SQLite default path, missing or partial Postgres settings with a message naming what is missing, password from file with surrounding whitespace removed, and no secret in any error text.
- The documentation lists every setting the code reads.

## Verify

`cd taskman && uv run pytest`; compare the settings named in the code with `taskman help` and the README.
