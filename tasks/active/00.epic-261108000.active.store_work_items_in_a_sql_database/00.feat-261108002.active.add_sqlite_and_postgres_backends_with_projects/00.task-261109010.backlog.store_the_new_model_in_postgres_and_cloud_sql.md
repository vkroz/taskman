## Outcome

The Postgres backend passes the same contract suite as SQLite, by connection string or by Cloud SQL unix socket.

## Scope

- Store implementation for Postgres 16, sharing SQL code with SQLite where the dialects agree.
- Connection by URL, or by socket directory, database, user and password (environment or secret file).
- Postgres contract tests run when a test database URL is set and are reported as skipped otherwise.

## Acceptance criteria

- The contract suite passes against Postgres 16.
- A connection through a unix socket directory works in a test.
- Without a test database URL, the Postgres tests show as skipped with the reason.

## Verify

`cd taskman && TASKMAN_TEST_DATABASE_URL=... uv run pytest`, and `uv run pytest` without it.
