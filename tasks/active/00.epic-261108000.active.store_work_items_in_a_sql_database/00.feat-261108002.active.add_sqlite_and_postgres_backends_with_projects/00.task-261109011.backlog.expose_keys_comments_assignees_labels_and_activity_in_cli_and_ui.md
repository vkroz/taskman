## Outcome

The CLI and the workspace UI work on the new model on a SQL backend.

## Scope

- Keys such as TM-42 everywhere an ID appears: arguments, output, JSON, UI links and checks. No 9-digit assumption remains.
- Comments replace `record`: add, list, and verification with result.
- Assignees and labels: set, clear, filter in `list`, `browse` and the UI.
- Activity history: shown by a command, in `context`, and in the UI item details.
- Consolidate and history are not offered on SQL backends (D8).

## Acceptance criteria

- CLI tests cover each new operation, success and rejection paths, on SQLite.
- UI API tests cover comments, assignees, labels and activity.
- A browser check creates an item, comments with a verification result, assigns, labels and closes it, and shows its activity.
- A search finds no 9-digit ID check in commands, help text or the UI.

## Verify

`cd taskman && uv run pytest`, plus the browser check against a SQLite database.
