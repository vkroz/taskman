## Outcome

The SQL schema of the approved data model exists with recorded versions, and one command upgrades a database.

## Scope

- Versioned schema changes applied in order; the applied version is stored in the database.
- An upgrade command, not named `migrate`, that creates a new database or upgrades an older one, on SQLite and Postgres.
- Concurrent upgrade runs do not corrupt the database.

## Acceptance criteria

- Upgrading an empty database reaches the current version on SQLite and on Postgres 16.
- Running the upgrade on a current database exits 0 and changes nothing.
- A database at an older test version upgrades to the current one.

## Verify

`cd taskman && uv run pytest` with and without a Postgres test database URL.
