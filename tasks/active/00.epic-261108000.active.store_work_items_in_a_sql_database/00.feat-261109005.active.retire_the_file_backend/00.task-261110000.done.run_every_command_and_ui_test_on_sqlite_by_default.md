## Outcome

Every command and UI test runs on SQLite, and SQLite is the default backend. The file backend still exists but no test depends on it except its own suite.

## Scope

- With `TASKMAN_BACKEND` unset, Taskman uses SQLite at the D7 default path.
- Command, workflow, UI and collection tests that create items through the file layout use a SQLite database in `tmp_path` instead. Tests of file-only behaviour (`migrate`, `worktree-status`, consolidation, layout checks, the file store suite) stay unchanged for removal in the next task.

## Acceptance criteria

- `uv run pytest` passes with and without a Postgres test database URL.
- Only tests of file-only behaviour still set `TASKMAN_TASKS_DIR`, create a `tasks/` tree, or use `FileStore`.
- An unset `TASKMAN_BACKEND` opens SQLite; a test proves it.

## Verify

`cd taskman && uv run pytest`; a search of `tests/` for `TASKMAN_TASKS_DIR`, `FileStore` and `backlog").mkdir`.
