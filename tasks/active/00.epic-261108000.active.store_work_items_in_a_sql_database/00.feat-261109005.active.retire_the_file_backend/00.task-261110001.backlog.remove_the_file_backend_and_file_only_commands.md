## Outcome

The file backend, its model modules and the file-only commands are gone from `taskman/src`.

## Scope

- Remove the file store, its layout, name, ID, YAML and lock modules where only the file backend uses them, the file-format tools `migrate` and `worktree-status`, `consolidate`, `history`, the UI's consolidation view and endpoints, and validate's layout checks. Validate keeps the dependency-graph checks.
- `TASKMAN_BACKEND=file` and `TASKMAN_TASKS_DIR` stop every command with a message that names the SQL settings.
- Remove code that existed only to tell the backends apart (capability flags, location-based child names, path-or-store helpers).
- Remove the tests of removed behaviour.

## Acceptance criteria

- A search of `taskman/src` finds no file-backend module, no `tasks/` layout code and no consolidation code.
- `uv run pytest` passes with and without a Postgres test database URL.
- With `TASKMAN_BACKEND=file` or `TASKMAN_TASKS_DIR` set, every command exits 2 with a message that names `TASKMAN_BACKEND=sqlite` or `postgres`; `help` and `version` still work.

## Verify

`cd taskman && uv run pytest`; searches of `taskman/src`; the refusal checked for each command.
