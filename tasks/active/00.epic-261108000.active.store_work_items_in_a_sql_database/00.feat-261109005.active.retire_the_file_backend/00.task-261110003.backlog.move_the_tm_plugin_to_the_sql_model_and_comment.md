## Outcome

The `tm` plugin's skills, rules and workflow reference describe the SQL model and use `comment` instead of `record`.

## Scope

- `plugins/tm/references/workflow.md`, `plugins/tm/rules/`, `plugins/tm/skills/*/SKILL.md` and agents under `plugins/tm/`.
- Remove the legacy shell script `plugins/tm/scripts/taskman.sh`; it reads only the file layout.
- Keys such as `TM-42`, `--project` for top-level items, comments, assignees, labels and activity.

## Acceptance criteria

- A search of `plugins/tm/` finds no `tasks/` path, `TASKMAN_TASKS_DIR`, `taskman record`, consolidation or reference to the shell script.
- Marketplace and plugin manifests validate, and `taskman install` succeeds for both platforms in a temporary home directory.

## Verify

Searches over `plugins/tm/`; manifest validation; `taskman install` smoke test.
