## Outcome

The workspace UI (`taskman ui`) reads and changes work items only through the storage interface.

## Scope

- Page data, item details, history, create, query, edit, discard, consolidate and reorder endpoints use the interface and the lifecycle layer from the write task.
- Page HTML and JavaScript stay unchanged unless an endpoint payload must change; payloads stay the same.

## Acceptance criteria

- `commands/ui.py` imports none of `model.layout`, `model.names`, `model.yaml_io`, `model.locking`.
- UI tests on `main` pass with unchanged assertions.
- Manual check: create, edit, reorder, discard a draft and consolidate in the browser against a temporary task tree, with the same results as on `main`.

## Verify

`cd taskman && uv run pytest tests/test_command_ui.py`, then the manual check.
