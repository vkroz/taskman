Add the shared Taskman ordering operation and durable storage behavior used by the CLI and UI.

## Acceptance criteria

- A supported CLI operation moves a task to a requested position and returns the resulting order.
- Reading the collection through the shared model returns the new order after a fresh process or reload.
- Moving upward and downward updates relative priority consistently, including moves to the first and last valid positions.
- The mutation preserves the reordered task's parent and lifecycle status.
- Invalid task IDs or positions fail without a partial ordering change.

## Local verification

- Add model and CLI tests for upward, downward, boundary and no-op moves, durable reload, metadata preservation and atomic failure.
- Run the focused tests, the full test suite and `taskman validate`.
