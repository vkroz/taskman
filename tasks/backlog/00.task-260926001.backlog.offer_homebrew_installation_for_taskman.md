## Outcome
A macOS developer can install the Taskman CLI with Homebrew, then use the existing Taskman command to install the Codex and Claude Code plugins. The current UV installation remains available.

## Acceptance criteria
- Provide a documented Homebrew installation route that installs a working `taskman` command without requiring the developer to install it with UV.
- Verify the installed command can run outside a repository and can install the existing plugins for supported hosts.
- Document installation and upgrade steps alongside the existing UV route; verify both routes remain usable.
- Run a clean local installation smoke test and the relevant Taskman test suite before completion.

## Decisions to resolve while defining
- Choose the Homebrew distribution channel and who maintains its release process.
- Decide whether Homebrew installs only the CLI or also offers an optional plugin setup step. It must not silently change Codex or Claude Code configuration.

This is an independent developer-experience step related to the unified multi-repository UI task; neither task blocks the other.
