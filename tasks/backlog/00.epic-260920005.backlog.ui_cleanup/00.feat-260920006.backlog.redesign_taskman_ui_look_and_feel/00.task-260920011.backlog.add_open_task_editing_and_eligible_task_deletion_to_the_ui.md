Expose task editing and deletion through the command design, backed by shared Taskman CLI behavior.

Acceptance:
- Edit an open task and display the persisted result.
- Closed requirements and evidence remain uneditable.
- Delete only items eligible under the explicitly established deletion rules; handle parent-child relationships and references without corrupting the task tree.
- Show actionable errors for prohibited operations; retain task creation.

Local check: CLI and UI success/failure cases for open, closed and referenced items; validate storage after permitted mutations. Deletion semantics must be resolved by the design task before implementation; do not infer unrestricted deletion.
