Implement filtering and sorting using the agreed design and metadata inventory, with CLI support for the underlying work-item queries.

Acceptance:
- Every defined work-item metadata attribute is filterable using the agreed semantics.
- Show current work and backlog without done items, or done items only.
- Scope results to an epic and its descendants; combine this with metadata and keyword filters.
- Sort predictably without obscuring hierarchy; distinguish contextual ancestors from matching results if the design retains ancestors.
- Clearing filters restores results and empty results are understandable.

Local check: automated query tests with mixed statuses, epics and metadata values, plus browser checks of the stated scenarios. Verify equivalent CLI results. Finalize controls and defaults after design.
