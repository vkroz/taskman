Design how completed tasks become documentation summaries without losing the reasons behind delivered changes.

Acceptance:
- Specify selection scope, summary content and destination, retrieval and handling of references and hierarchy.
- Explicitly resolve whether original completed records are archived or removed after summarization; do not assume authorization to erase records.
- Describe how closed-record immutability is preserved and how consolidated items leave ordinary task lists.
- Define failure recovery so a failed summary write cannot lose task history.

Local check: walk through completed parent/child work with references from open tasks and a failed documentation write. Record a concrete proposal and remaining decisions before implementation.
