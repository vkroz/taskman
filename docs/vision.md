# Taskman

Taskman lets engineers coordinate development work across coding agents while keeping requirements, decisions and verification available to the whole team.

Its core is a shared task tree. A person can enter an epic in the UI; an agent can decompose it, execute ready tasks, record decisions and checks, and hand the next step to another agent. The UI shows the resulting structure and evidence. Codex and Claude Code use one CLI and the same records.

Taskman is a general-purpose open-source tool. Reservoir provides a real project for testing it; Reservoir-specific behavior belongs outside the core. The immediate goal is a dependable local development workflow. Building a commercial autonomous software factory or deploying users' applications is outside that goal.
